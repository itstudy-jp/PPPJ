## プロジェクト概要
仮想企業のペルソナを用いて、その企業の要件に合わせた NWインフラ と WEBアプリケーション を1年ほどかけて構築・運用するプロジェクトです。
## 目的
資格以外の勉強の場を作るというところから始まったプロジェクトです。
できるだけ実務的に進めて、現場ベースの知識・ナレッジの獲得を目指します。
- 現場ベースの知識
- 企業NWのインフラ構築
- Webアプリ開発・運用
- セキュリティ

## 参加について
このサーバーにいる方であれば、活動内容は誰でも自由に見ることができます！

### 参加を希望する方
まずは、プロジェクト資料やメッセージのやり取りを見たり、定例や打ち合わせに顔を出して雰囲気を掴んでみてください！（ミュートでOK）

※ 参加希望の方は、パプさんまたはAkiさんまでご連絡ください。

### 稼働について
基本自由参加ですが、稼働がほとんど見られない場合は一度メンバーから外れていただくことがあります。
また参加したくなったらいつでもお声がけください

## ペルソナ企業について

**株式会社 Papu tech solutions**
- 規模：50人規模のSaaS系スタートアップ
- 拠点：東京 人形町のビル（ワンフロア）

### 対応が急務となっている課題

- 主力製品となるWEBアプリケーションの開発
- 通常業務を含む会社運用に必要なNWインフラの構築
- 上記を安全に稼働させるためのセキュリティ整備

## 会議体
### 実施スケジュール
隔週：日曜日 21:00〜
### 会議のファシリテーターについて
ファシリテーターは基本、PMにて行う。  
各チームメンバーについては、チーム・メンバー紹介に示す。
### 議題内容
- 各チームからの進捗報告
### 議事録
- 管理方針  
  議事録は下記ディレクトリにて管理する。  
  ファイルの命名規則ついては命名形式に従う。  
  議事録については、会議後3日以内でGitHubにアップロードすること。
  ```
  │
  └── docs
      └── minutes
          ├── template.md
          └── yyyymmdd_minutes.md
  ```
- 記載方針  
  議事録はtemplate.mdを活用すること  
  また、テンプレートにない項目でも、必要に応じ追加すること  
- 書記  
  書記については、運用メンバーの持ち回りとする。
